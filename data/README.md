# Source data

Download the archive from the [Olist Brazilian E-Commerce Public Dataset on Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) and extract it locally, for example into `data/raw/`. Keep the original filenames. The report's documented inputs are:

- `olist_orders_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_products_dataset.csv`
- `product_category_name_translation.csv`

Point the Power Query sources to these local files before refreshing. The downloaded CSVs are kept outside version control. See the [data dictionary](../docs/data_dictionary.md) for the source grain and reporting fields.
